The source design-system README credits Nathan Dumlao via Unsplash: <https://unsplash.com/fr/photos/tasse-de-latte-sur-la-table-Ic8RmXGyfNc>. Converted with FFmpeg WebP quality 78 for the landing.

- `assets/fonts/poppins-*.woff2`: supplied local IndiqAI prototype fonts; license included as `assets/fonts/OFL.txt`.
- Inline SVG icons are authored for this page. The loyalty-card UI is illustrative and is not a customer account or working QR code.
